# sp-standard-bus.glb

Malha 3D autoral criada para o Pátio Monitor. Licença do modelo e do script de geração: CC0 1.0 Universal (https://creativecommons.org/publicdomain/zero/1.0/). Pintura e letreiro ilustrativos do projeto. Nenhum modelo, imagem, marca oficial ou textura de videogame foi incorporado.

Fonte editável: `assets/build_bus.py`. Blender 4.3.2, glTF 2.0. Eixos glTF: +Y para cima, +Z na frente, +X no lado das portas. Uma unidade equivale a um metro. A origem do conjunto é o centro do veículo no solo. Os nós são nomeados por família e material para manter a geometria identificável e reduzir chamadas de desenho.
